RookOverlay Analytics

Ferramenta em desenvolvimento para estudar estatísticas de partidas concluídas de VALORANT com dados obtidos por meios autorizados.

Status: proposta cadastrada e URL verificada no portal da Riot. Aprovação da API de produção pendente. Sem conexão ativa com Riot Sign On.

O que já existe

Importação

Entrada local de JSON de partida concluída no formato oficial.

Estatísticas

Eliminações, mortes, assistências, K/D e estimativa de pontos por rodada.

Relatórios

Saída HTML para leitura e arquivos CSV/JSON para análise adicional.

Como funciona

  1. O usuário obtém, de fonte autorizada, um JSON de partida concluída.
  2. Importa o arquivo no aplicativo local.
  3. O aplicativo processa as estatísticas e gera o relatório.
  4. Após eventual aprovação, será desenvolvida conexão RSO com consentimento explícito do jogador.

Limites do projeto

O módulo analítico não oferece posições ocultas de adversários, ESP ao vivo, orientação tática em tempo real ou interferência no Vanguard. Um módulo gráfico separado de overlay de desktop não recebe informações do jogo.

Privacidade

Dados de contas somente serão consultados por interfaces oficialmente autorizadas e com opt-in aplicável. A solução não solicita senhas da Riot.
